# powershell-scripts

Diverse PowerShell-script för Windows. Varje script är fristående och har fullständig hjälp inbyggd — kör `Get-Help .\<script>.ps1 -Full` för detaljer.

## Script

| Script | Beskrivning |
| --- | --- |
| [Copy-ToSharePoint.ps1](Copy-ToSharePoint.ps1) | Kopierar en mapp från en nätverksenhet till en mapp i ett SharePoint Online-dokumentbibliotek, med rclone i botten och en robocopy-liknande konsol (progressbar, en rad per fil, summeringstabell). Målet anges som URL:en från webbläsarens adressfält (`-Url`); tenant, site, bibliotek och mapp läses ut automatiskt. Laddar ned rclone vid behov (pinnad version, SHA-256-verifierad), använder en remote per tenant som namnges efter tenanten (en webbläsarinloggning per tenant, `-SignIn` förnyar den) och slår upp biblioteket via Microsoft Graph med cache. Robocopy-motsvarigheter: `-Mirror` (/MIR), `-ExcludeFile`/`-ExcludeDir` (/XF /XD), `-Retries`/`-RetryWaitSeconds` (/R /W), `-Transfers` (/MT), `-WhatIf` (/L), `-LogFile` (/LOG), `-NoFileList` (/NFL), `-BandwidthLimit` (/IPG). |
| [Install-PSPrompt.ps1](Install-PSPrompt.ps1) | Installerar en delad tvåradsprompt för Windows PowerShell 5.1 och PowerShell 7+, med git-status, admin-indikator, trunkerad sökväg och tid för långsamma kommandon. Skriver prompten till en delad fil och injicerar en markör-avgränsad stub i berörda profiler. Stöder `-Scope AllUsers` (begär själv admin via UAC), `CurrentUser` och `Auto`, samt `-Uninstall` och `-WhatIf`. |
| [Set-ComputerText.ps1](Set-ComputerText.ps1) | Visar en svag, click-through-overlay med en textrad (default datornamnet) i nedre högra hörnet av primärskärmen. Körs icke-blockerande: overlayn lever i en egen frikopplad process så anroparen returnerar direkt (exit 0 vid start, non-zero vid fel) — säkert att köra från RMM (t.ex. NinjaOne, som inloggad användare). Ny körning med `-Text` uppdaterar texten live utan omstart; `-Stop` (alias `-Clear`) tar bort den. Kräver den interaktiva användarens session — ett GUI kan inte ritas från SYSTEM/session 0. |
| [Invoke-NetScan.ps1](Invoke-NetScan.ps1) | Upptäcker värdar på ett subnät (`-Subnet` CIDR) eller IP-intervall (`-StartIP`/`-EndIP`) via ICMP-svep, ARP-/grann-cache, valfri TCP-portscan, namnuppslag (reverse-DNS med NetBIOS-/mDNS-fallback) och IEEE OUI-vendoruppslag. Visar en tabell per värd plus en summeringsrad (antal hittade, hur många med MAC); `-PassThru` ger objekten på pipelinen i stället, och `-CsvPath` skriver CSV. ICMP-svepet gör om-försök och använder en separat, lägre samtidighet (`-IcmpThrottle`/`-IcmpRetries`) för att inte tappa levande värdar. För lokala nät görs ett käll-bundet ARP-svep (`SendARP`) som hämtar MAC direkt över L2 och kringgår en ev. tunnel-route som annars stjäl trafiken (`-SourceAddress`/`-SkipArpSweep`). `-Slow` för IDS-vänlig takt, `-ArpOnly` för passiv avläsning av grann-cachen. |
