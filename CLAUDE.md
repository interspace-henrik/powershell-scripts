# powershell-scripts

Samling av fristående PowerShell-diversescript.

## Regler

- `README.md` listar alla script i repot med en kort beskrivning. Håll den uppdaterad: när ett script läggs till, byter namn, tas bort eller ändrar beteende väsentligt ska README.md uppdateras i samma ändring.
- Varje script ska ha kommentarbaserad hjälp (`.SYNOPSIS`, `.DESCRIPTION`, exempel) så att `Get-Help` fungerar.
